# README 统一模板 / Shared README template

本模板规定结构，产品内容按实际实现填写；不要发布未替换的变量。

```markdown
# Zotero <Product>

Zotero Flow Series · <产品职责 / Product role>

**<一句用途 / One-sentence purpose>**

[简体中文](README.md) · [English](README.en.md)
[当前版本](<exact-release>) · [下载 XPI](<exact-asset>) · [问题反馈](<issues>)
```

| 锚点 | 中文章节 | English section | 内容要求 |
|---|---|---|---|
| `overview` | 产品定位 | Overview | 用途与适合谁 / Purpose and audience |
| `installation` | 安装与更新 | Installation and updates | 精确版本、XPI、更新通道 / Version, XPI, update feed |
| `quick-start` | 快速开始 | Quick start | 三步得到结果 / Three steps to a result |
| `features` | 核心功能 | Key features | 四组可用功能 / Four implemented groups |
| `settings` | 设置与使用 | Settings | 入口、主要开关、生效时机 / Entry and effect |
| `data` | 数据、同步与外部服务 | Data, sync, and services | 本地/云端/API/隐私 / Local, remote, API, privacy |
| `compatibility` | 兼容性与验证范围 | Compatibility and validation | 清单范围与实际验证分别列示 / Declared vs tested |
| `troubleshooting` | 常见问题 | Troubleshooting | 具体症状与下一步 / Symptom and action |
| `development` | 开发与详细文档 | Development and documentation | 真实命令与详细指南 / Real commands and guides |
| `series` | 系列产品 | The Flow series | 相同系列目录 / Shared catalog |
| `license` | 项目来源与许可 | Origin and license | 实际许可和完整来源 / Actual license and attribution |

下载链接必须指向实际 Release 的 XPI。不要用 Source code ZIP、未经确认的仓库地址或占位截图代替安装和界面说明。文档改动应保留原详细指南，修复原入口并校验相对链接。
