# Zotero CiteFlow v13.0.11 Release Notes

**Release Date**: 2026-11-04  
**Version**: `13.0.11`  
**Compatibility**: Zotero `10.0` – `12.*`

## Highlights

1. **Multi-Window Unload Fallback & Trashed Item Guard (`src/hooks.mjs`, `src/addon.mjs`)**:
   - `detachWindow` gracefully falls back to remaining active windows in `windowBindings` and `Zotero.getMainWindows()` rather than unconditionally setting global window variables to `undefined`, preventing `TypeError` when closing secondary main windows.
   - `addon.api.citeItems` encapsulates safe item resolution and strictly rejects `deleted` or `inTrash` items before dispatching Word citation injection.
2. **Temporary Collection Teardown Ordering & Key Hygiene (`src/modules/citation/preferences-sync.mjs`)**:
   - Inverted and properly awaited collection destruction when `collections.enable` is toggled off: detaches active session references and invalidates indexes first, awaits `eraseTx()`, cleans up `_temporaryCollectionKeys`, saves preferences, and executes `clearStaleArtifacts()`, eradicating orphaned collection keys.
3. **Preferences Interlocking, Single-Group Accordion & Typography Alignment (`preferences.mjs`, `preferences.xhtml`, `preferences.css`)**:
   - Invokes `updateDependencies()` on panel initialization and settings reset so control dependencies take effect immediately.
   - Accordion cards strictly follow the single open-group standard (only Module 1 opens by default).
   - Removed hardcoded Chinese text from version info in `preferences.xhtml`, allowing clean Fluent localization.
   - Fixed Level 1 top overview description in Module 4 to remain flush with the 16px content line (0px offset).
4. **SHA-512 Update Manifest Compliance (`scripts/build.ps1`, `tests/package.test.cjs`, `update.json`)**:
   - Updated package builder, tests, and feed manifest to use standard `sha512:` hash prefixes as mandated by `AGENTS.md` 205/227.
