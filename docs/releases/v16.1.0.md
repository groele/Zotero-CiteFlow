# Zotero CiteFlow 16.1.0

**发布日期**：2026-11-12  
**适用范围**：Zotero `10.0` - `12.*`

## 核心修复与改进清单

1. **Zotero 10+ 原生拖拽与条目树兼容性修复**：
   - `Views.dragCite()` 通过 `supportsNativeDropTarget()` 限定仅在 Windows 接管 Word 拖拽；macOS/Linux 自动禁用拖拽接管并保留 Zotero 原生快速复制行为。
   - 拖拽开始时优先调用原生 `itemsView.onDragStart` 保留 `zotero/item` 拖入文集与废纸篓的完整负载，仅清除 `text/html` 与置空 `text/plain`。
   - `createCitationColumn()` 移除过时的 `defaultIn` / `disabledIn` 属性，迁移为 `enabledTreeIDs: ["main"]`。
   - `ViewsIconPatch._addSortedRow()` 精确保存与还原排序行原本的自有 `isCollection` 属性，仅清理插件自身注入的原型遮罩函数。

2. **并发异步竞态、启动容错与生命周期收口**：
   - `ViewsWindowPrep.prepareWindow()` 在 `itemsView` 或 `collectionTreeRows` 未就绪时记录日志并返回 `false`；`hooks.onStartup()` / `onMainWindowLoad()` 容错缺失主窗口或单窗口挂载异常，确保设置面板与引用监听稳定运行。
   - `preferences-sync.ts` 增加 `_listenerStopped` 与跨 `await` 中途取消检查（关闭集合功能、监听停止、会话关闭中或会话实例替换均立即中止）。
   - `formatting.ts` 为 `_scheduleSessionRefresh()` 与延时刷新回调加入 `!session || session.closing` 双重守卫，避免窗口或文档关闭后触发无效刷新。
   - `word-integration.ts` 的 `ensureSession()` 在既有会话因缺少文集重新初始化时标记 `session.pending = true`，并在失败路径仅删除新建空会话、保留既有合法会话。
   - `cite.ts` 追踪所有临时包装的 WinWord `application` 实例，在 `finally` 中通过 `restorePatchedApplications()` 完整恢复原生 `getActiveDocument`。
   - `CitationCollections.clearStaleArtifacts()` 增加 `_clearStaleManagedTags()` 在无活跃 Word 会话时清理孤立托管标签并保留手工标签；`_renameCollection()` 成功后重置重试计数器。

3. **设置面板、多语言本地化与构建守卫加固**：
   - `preferences.ts` 通过 `esbuild` 编译期注入 `__buildVersion__` 与 `__buildDate__` 动态驱动徽标、构建日期与下载链接 `data-l10n-args`，`.ftl` 移除硬编码版本号改用 `v{ $version }`、清理死键并对齐中英文引用标签提示语。
   - 非 Windows 平台在设置面板禁用“拖动文献条目引用”开关；取消勾选“引用后自动维护标签”时同步清除文本输入框错误状态并恢复已保存值；修复窄屏媒体查询下的 `.zoterocitation-subordinate-row` 缩进优先级。
   - `scripts/build.ps1` 增加 `node --check chrome/content/preferences.js` 语法检查、规范 ZIP 条目斜杠为 `/` 并同步根目录 `update.json`；`scripts/architecture-guard.mjs` 执行 13 项全链路版本、FTL、API、CSS 与哈希一致守卫。

4. **CSL 样式与工具脚本修复**：
   - 修复 `csl/compact-journal-reference.csl` 缺失 `variable="title"`、`variable="container-title"`、空 `<text>` 元素、DOI 前缀、卷期空格与未来 `<published>` 时间戳问题。
   - 修复 `tools/generate_all_icons.py`、`tsconfig.json`、`AGENTS.md` 与 `scripts/start-native-test.ps1` 中的历史配置漂移。
