# Zotero CiteFlow v13.0.9 Release Notes

**Release Date**: 2026-11-03  
**Version**: `13.0.9`  
**Compatibility**: Zotero `10.0` – `12.*`

## Highlights

1. **Multi-Window Tree Enumeration & Dynamic Expand Self-Healing (`src/modules/views/icon-patch.mjs`)**:
   - `_getAllCollectionsViews` enumerates across all active main and detached windows to guarantee that CiteFlow Word collections remain positioned immediately above `My Publications` in every visible tree view.
   - Enhanced `_expandRow` monkey-patch to immediately invoke `_refreshRowMap()` and `tree.invalidate()` upon slice reordering, preventing row-index drift when expanding collapsed libraries.
2. **Academic Citation Text Sanitization & Deduplication (`src/modules/citation/formatting.mjs`)**:
   - Strips Unicode zero-width formatting characters (`\u200B-\u200F`, `\uFEFF`) and invisible control codes from plain citation text.
   - Automatically collapses repeated identical citation labels for items cited multiple times within composite fields.
3. **Transactional Membership Robustness & Library Isolation (`src/modules/citation/collections.mjs`, `src/modules/citation/formatting.mjs`)**:
   - Guards `syncCollectionItems` transactional DB executions with isolated `try/catch` and error logging, preventing intermittent DB locks from stalling session refresh cycles.
   - Aligns top-level item member filtering with `collection.libraryID` to preserve strict library boundary isolation.
4. **Source Code Cleanliness**:
   - Strictly maintained all 27 source modules under `<= 360` lines of code.
