# Zotero CiteFlow v13.0.7 Release Notes

**Release Date**: 2026-11-03  
**Version**: `13.0.7`  
**Compatibility**: Zotero `10.0` – `12.*`

## Highlights

1. **Exact Drop-Target Word Window Title Capture (`src/modules/drop-target.mjs`)**:
   - When confirming `winword.exe` during drag-and-drop (`resolveWordDropTarget`), CiteFlow now resolves the top-level window handle via `GetAncestor(targetWindow, GA_ROOT)` and reads its title via `GetWindowTextW`, allowing `execCommand("WinWord", "addEditCitation", null, 1)` to immediately name the session collection after the exact target Word document instead of `Word 文档（待识别） 1`.
2. **Background Self-Healing for Pending & Newly-Saved Word Documents (`src/modules/citation/word-integration.mjs`, `src/modules/citation/document-naming.mjs`)**:
   - `_syncSessionDocumentName` automatically resolves pending `Word 文档（待识别） N` collections and updates `window-title:` sessions when an unsaved document (`文档1`) is saved to disk (`论文.docx`) using unambiguous `OpusApp` window enumeration (`probeWordWindowTitles`), while refusing to guess when multiple unidentified Word windows are open simultaneously.
3. **Direct Initial Collection Naming (`src/modules/citation/collections.mjs`)**:
   - `initCollection` and `ensureSession` immediately apply known document names upon collection creation without first creating a `Word 文档（待识别） 1` placeholder.
4. **Resilient SharePoint/OneDrive URL & Word Title Parsing (`src/modules/citation/document-naming.mjs`)**:
   - `_parseWordWindowTitle` strips Word status suffixes (`- Word`, `[兼容模式]`, `[Compatibility Mode]`, `- 已保存到此电脑`, `- Saved to OneDrive`, `- 只读`, `[Read-Only]`, etc.) while preserving hyphenated filenames (`My-Paper - Part 1.docx`).
   - `_getDocumentDisplayName` extracts `?file=` parameters from SharePoint/WOPI viewer URLs (`Doc.aspx`, `WopiFrame.aspx`) and tolerates unescaped `%` characters in cloud URLs without throwing `URIError`.
