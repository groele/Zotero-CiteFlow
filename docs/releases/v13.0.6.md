# Zotero CiteFlow v13.0.6 Release Notes

**Release Date**: 2026-11-03  
**Version**: `13.0.6`  
**Compatibility**: Zotero `10.0` – `12.*`

## Highlights

1. **Active Session Collection Protection (`src/modules/citation/collections.mjs`)**:
   - `_clearStaleTemporaryCollections` now builds an `activeKeys` whitelist from all active, non-closing sessions (`!s.closing && s.collection?.key`), guaranteeing that `clearStaleArtifacts()` can never erase a collection belonging to an active Word session.
2. **Preemptive Polling Yield During Word `execCommand` (`src/modules/citation/word-integration.mjs`)**:
   - `_syncActiveWordSessions` now checks `if (this._listenerStopped || this._isExecCommandRunning) break;` inside its session loop before invoking `refreshSessionCitations`, immediately yielding the background poll if a native Word command begins mid-cycle.
3. **Deterministic `_pendingCollectionNames` Cleanup & `itemsView` Deduplication (`order-cache.mjs`, `lifecycle.mjs`, `formatting.mjs`)**:
   - `cleanupSessionState` and `_resetInternalTrackingMaps` now deterministically clean up `_pendingCollectionNames` and reset `_pendingCollectionNumber = 0`.
   - `scheduleItemsViewRefresh` deduplicates `itemsView` instances via `seenViews = new Set()`.
4. **Settings Panel 14px Control Typography & Version Badge Sync (`chrome/content/preferences.css`, `chrome/content/preferences.xhtml`)**:
   - Upgraded `.zoterocitation-number-row label`, `input[type="number"]`, `input[type="text"]`, and `button` font-size from `13px` to **`14px`** per `AGENTS.md` Section 4.1, and synchronized the header `.zoterocitation-version-badge` to `v13.0.6`.

## Verification

- **Automated Test Suite**: 50/50 top-level tests passed (`npm test`).
- **Tag & Version Validation**: `python scripts/release-tags.py --self-test` passed.
