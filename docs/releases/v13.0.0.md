# Zotero CiteFlow 13.0.0 — Major Milestone Release

Date: 2026-11-02. Status: Production Release. Annotated tag `v13.0.0`.

## 核心重大升级概览

1. **函数级深度治理与 11 大领域分层**：
   - 彻底梳理历史堆砌代码，对全量函数按职责分门别类，划分 11 大领域（常量配置、子系统细粒度初始化、遥测诊断、持久化序列化、路径规范化、临时集合治理、Word 进程拦截、顺序推断与签名缓存、标签治理只读保护、引文格式化与视图刷新、生命周期销毁）；
   - 剔除无用死代码，全量保留 JSDoc 规范注解，确保每一个函数的参数边界、返回值与副作用完全清晰可维护。

2. **商业级设置面板与 40px 黄金基准对齐**：
   - 严格落实 Zotero Flow 2026-11-02 统一基准：16px 卡片内边距，Level 2 文字与 Level 3 从属子项严格对齐于 40px 垂直基准线；
   - 100% Fluent 国际化覆盖，零硬编码字符，支持完整键盘焦点与无障碍属性（ARIA）。

3. **数据安全性与只读保护（Read-only Guard）**：
   - 全面引入 `item.isEditable()` 原生安全校验；
   - 在只读群组库（Group Library）与回收站（Trash）中操作时，自动阻断非法标签写入并记录审计日志，杜绝脏写与同步冲突。

4. **宿主平台与 Gecko 运行时现代化**：
   - 严格声明支持 Zotero `10.0` 至 `12.*`；
   - 构建目标全面对齐 Firefox 140+ / Gecko 153+ 标准现代 ESM 运行时。

## 验证与验收记录

- **全量回归测试**：通过全部 37 项自动化测试套件（覆盖数据稳定性、Word 会话集成、设置面板交互、首选项绑定及打包规范）。
- **SHA-256 完整性**：参考引文模块保持字节级严格对齐，安装包哈希经自动与离线校验一致。
