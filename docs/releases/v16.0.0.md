# Zotero CiteFlow 16.0.0

Zotero CiteFlow 正式发布 **16.0.0** 大版本，标志着全系统一大版本（Zotero Flow Unified Major Release 16.0.0）正式确立。

## 🌟 核心升级与特性

1. **统一全系大版本号**：跃升至 16.0.0，与 Zotero Flow 家族其余六大插件保持完全一致的版本节拍与契约；
2. **纯净现代化架构底座**：严格执行 360 行单文件架构红线（0 债务），34 个 TypeScript 源码模块全部通过严格静态类型检查；
3. **架构守卫与自动化套件**：建立 13 项硬约束架构守卫自动化检查套件，杜绝循环依赖与过时 API；
4. **设置面板模块化规范**：基于 5 大业务流转模块与 40px 黄金垂直对齐线，全面落实 Fluent 本地化中英双语对齐；
5. **Zotero 10 ~ 12 现代兼容**：基于现代 Gecko 运行时，支持多窗口遍历、微任务自愈与 AbortController 生命周期清理。
