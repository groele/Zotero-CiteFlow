# Zotero CiteFlow 13.0.2 — Multi-File Domain Modularization & Deep Function Governance

Date: 2026-11-03. Status: Production Release. Annotated tag `v13.0.2`.

## 核心提升要点

1. **彻底消除单文件代码堆砌（27 个独立源码模块）**：
   - 将原 1,913 行的 `src/modules/citation.mjs` 拆分为 `src/modules/citation/` 下的 11 个独立领域模块（`constants.mjs`、`initializers.mjs`、`telemetry.mjs`、`preferences-sync.mjs`、`document-naming.mjs`、`collections.mjs`、`word-integration.mjs`、`order-cache.mjs`、`tag-governance.mjs`、`formatting.mjs`、`lifecycle.mjs`），主入口 `citation.mjs` 精简为 62 行门面协调器；
   - 将原 462 行的 `src/modules/views.mjs` 拆分为 `src/modules/views/` 下的 5 个独立视图模块（`session-index.mjs`、`column-manager.mjs`、`window-prep.mjs`、`drag-cite.mjs`、`icon-patch.mjs`），主入口 `views.mjs` 精简为 140 行核心生命周期协调器；
   - 全仓库所有 `src/` 源码模块单文件最大行数不超过 350 行。

2. **超长复杂函数逐一细粒度拆分**：
   - 拆解 `_syncCitationTags`（原 140 行）为 `_collectActiveCitedIDSet`、`_resolveItemByID`、`_hasItemTag`、`_syncActiveItemCitationTag`、`_removeUncitedManagedItemTag`；
   - 拆解 `_installWordIntegrationHooks`（原 120 行）为 `_createGetSessionWrapper`、`_createExecCommandWrapper`、`_handlePostExecCommand`；
   - 拆解 `_refreshSessionCitations`（原 89 行）为 `_readSessionCitationSnapshots`、`_handleEmptyCitationSnapshot`；
   - 拆解 `_performClear`（原 90 行）为 `_restoreWordIntegrationHooks`、`_resetInternalTrackingMaps`；
   - 拆解 `listener`、`clearStaleArtifacts`、`_applyCitations`、`getCitationText`，提炼 `_pruneMissingWordSessions`、`_syncActiveWordSessions`、`_clearStaleTemporaryCollections`、`_clearStaleManagedSearches`、`_formatItemPlainCitation`、`_resolveSelectedCollectionSessions`。

3. **全量验证与模块化架构防线**：
   - 新增 `tests/modular-architecture.test.mjs`，对单文件行数上限（≤360 行）、72 个 `Citation` 原型方法与 `Views` 原型方法零冲突挂载及细粒度辅助函数完整性进行自动化守卫；
   - 全量 40 项顶层测试套件 100% 通过。
