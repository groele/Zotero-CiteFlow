# Zotero CiteFlow 16.2.0

**发布日期**：2026-11-12  
**适用范围**：Zotero `10.0` - `12.*`

## 核心修复与稳定性增强清单

1. **多文档前景焦点联动（P1-B）与窗口标题/路径多重消歧**：
   - 在 `src/modules/drop-target.ts` 抽取 `readForegroundWordTitle()` 并导出轻量只读接口 `probeForegroundWordTitle()`（经由 `src/hooks.ts` 挂载与清理），配合 [session-sync-helpers.ts](src/modules/citation/session-sync-helpers.ts) 中的 `syncForegroundActiveSession()`，仅当前台 `WINWORD.EXE` 窗口标题唯一匹配单个活跃文档会话时同步 `activeSessionID` 与视图刷新，焦点位于 Zotero 或存在多个同名文档时绝不盲猜切换。
   - 在 `src/modules/citation/document-naming.ts` 的 `_resolveFallbackDocumentId()` 中以多重集差集（multiset subtraction）替代原本会折叠重名项的 `new Set(...)`，对重复 `window-title:` 施加歧义拒绝保护；同时新增 `_extractDocumentParentQualifier()` 与 `_getUniqueCollectionDisplayName()` 为不同路径的同名文档附加父目录限定，并保持 `_getDocumentDisplayName()` 纯函数语义兼容既有契约。

2. **轮询冷却、自适应退避与并发重入补偿**：
   - 在 `session-sync-helpers.ts`、`word-integration.ts`、`initializers.ts` 与 `lifecycle.ts` 引入 `WINDOW_PROBE_COOLDOWN_MS = 3000` 后台枚举冷却门控与 `LISTENER_IDLE_BACKOFF_TICKS = 5` / `LISTENER_MAX_IDLE_INTERVAL_MS = 3000` 自适应空闲退避，以及基于 `finalizeExecCommandCycle()` 的并发重入完成补偿，在 Word 活跃操作与会话变更时立即恢复高频检测。

3. **快照输入脏检查（Dirty-Check）与条目列表行级定点重绘**：
   - 新增 `src/modules/citation/refresh-helpers.ts`，结合 `collections.ts` 与 `formatting.ts` 引入 `buildRefreshInputFingerprint()` 指纹比对以跳过无变化的重复快照格式化与集合写入；并在 Zotero `10.0.8` 实证 `itemTree` API（`invalidateRowCache`、`getRowIndexByID`、`getSortField` / `getSortFields`、`tree.invalidateRow`）可用且未按引用列排序或超批量阈值时执行行级局部失效，接口缺失或存在排序异常时自动回退至 `refreshAndMaintainSelection()`。

4. **并发拖拽防重提示（完整保留锁定的 Word 内核 SHA-256 基线）**：
   - 在 `src/addon.ts` 的 `Addon.api.citeItems` 外层通过 `_citeInFlight` 与节流 ≥ `2000ms` 的 `_notifyCiteInFlight()`（`Zotero.ProgressWindow`）给出本地化非阻塞占线提示，同步补充中英文 Fluent 键 `zoterocitation-cite-in-flight` 及个人文库提示边界，同时保持 `src/modules/cite.ts` 与其受保护的 SHA-256 基线字节级一致。

5. **技术文档纠偏与自动化稳定性验证扩展**：
   - 在 `README.md` 与 `README.en.md` 明确 CSL 样式适用说明与 CiteFlow 核心追踪/拖拽仅支持 Microsoft Word、不适配 WPS Writer 的边界，修正 `CORE-TECHNICAL-MAINTENANCE.md` 中过时偏好键名与模块清单。
   - 新增 `tests/enhancement-stability.test.mjs` 6 项专项测试，全仓 36 个 TypeScript 源码文件严格保持 `<= 360` 行零债务，通过 `tsc --noEmit`、13 项 `architecture-guard.mjs` 检查及全量 `87` 项自动化测试。
