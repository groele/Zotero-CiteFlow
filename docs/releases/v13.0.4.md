# Zotero CiteFlow v13.0.4 阶段说明（单条目瞬态缺失恢复、幽灵会话标签隔离与双模态 ID 深度加固）

## 1. 核心目标

在 `v13.0.3` 完成学术引文序数决定性、双向整体快照防呆与回收站拦截的基础上，进一步深入排查**“部分条目瞬态未就绪”、“多文档关闭竞态下的幽灵会话标签残留”以及“视图层字符串/数字 ID 键跨层查找”**等边缘深水区隐患，实现全链路零死角的商业级可靠性。

## 2. 五大深度优化与加固

1. **单条目瞬态缺失恢复与同序号文本继承（`src/modules/citation/formatting.mjs`）**
   - **并集覆盖**：在 `_applyCitations` 中，将 `Object.keys(citationsByItemID)` 与 `sortedItemIDs` 合并为 `citationIDKeySet`。即便 Word 在更新某个具体引文域时 `citationsByItemID` 暂时漏掉了该条目，只要它仍在文档引文顺序表 `sortedItemIDs` 中，就不会被移出临时集合或从列表回显中消失。
   - **同序号平滑回退**：在 `_formatItemPlainCitation` 中，若某个条目的 `citationsByItemID[id]` 瞬态为空，优先检查上一帧 `oldIdData[id]?.plainCitation` 是否已具备相同序号前缀（`${order}: `）且非错误占位；若是则直接沿用，彻底消除编辑引文时的 `(error)` 闪烁。

2. **正在关闭/幽灵会话标签防污染（`src/modules/citation/tag-governance.mjs`）**
   - 在 `_collectActiveCitedIDSet` 中显式排除 `this.sessions?.[sid]?.closing === true` 的会话，以及既不在 `Zotero.Integration.sessions` 也不在 `this.sessions` 中的孤立会话键，保证关闭 Word 文档后不再有任何幽灵引用阻碍插件标签清理。

3. **视图层双模态 Item ID 查找与非法 ID 拦截（`src/modules/views/session-index.mjs`）**
   - 在 `_getSessionIndex` 与 `getCitationText(itemID)` 中强制校验 `Number.isSafeInteger(numericID) && numericID > 0`，并同时支持数值键与字符串键双模态读取 `session.idData`，确保 Zotero 虚拟树传入任意形态的合法 ID 均能精准命中。

4. **临时集合同步正整数过滤加固（`src/modules/citation/collections.mjs`）**
   - 在 `syncCollectionItems` 中将 `Number.isInteger` 升级为 `Number.isSafeInteger(id) && id > 0`，杜绝 `0` 或负数 ID 触发无效的 `Zotero.DB.executeTransaction` 事务。

5. **历史标签状态迁移防污染（`src/modules/citation/preferences-sync.mjs`）**
   - 在 `_loadLegacyManagedTagState` 中严格校验历史保存的条目 ID 必须为正安全整数，防止异常配置数据混入 `_managedCitationTagIDs`。
