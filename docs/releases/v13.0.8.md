# Zotero CiteFlow v13.0.8 Release Notes

**Release Date**: 2026-11-03  
**Version**: `13.0.8`  
**Compatibility**: Zotero `10.0` – `12.*`

## Highlights

1. **Word Collection Tree Positioning Above My Publications (`src/modules/views/icon-patch.mjs`, `src/modules/citation/collections.mjs`)**:
   - Solves the ICU collation sorting discrepancy in Zotero 10 where Chinese-named Word collections (e.g. `新建 Microsoft Word 文档.docx`) were automatically positioned between numbered collections (`06_Reference Shelf`) and Latin collections (`Daily Folder`).
   - Implements collection tree slice reordering (`_reorderCitationRowsInSlice` / `repositionCitationCollections`) to place all CiteFlow Word collections immediately above the bottom virtual row group starting at `My Publications` (`publications`).
   - Dynamically refreshes `collectionsView._rowMap` and synchronizes `selection.focused`, `selection.pivot`, and `selection.selected` to guarantee zero selection loss or drift during reordering.
   - Intercepts collection addition and renaming (`_addSortedRow` / `_insertCitationRowAbovePublications`) so newly added user collections stay above Word collections, and Word collections automatically drop into place above `My Publications`.
2. **Complete Cleanup & Renaming of Legacy `v40` Artifacts**:
   - Standardized all legacy test files into clear, domain-specific suites:
     - `tests/v40-stability.test.js` -> `tests/citation-stability.test.js`
     - `tests/v4002-data.test.js` -> `tests/citation-data.test.js`
     - `tests/v4002-ui.test.js` -> `tests/citation-ui.test.js`
     - `tests/v4002-word.test.js` -> `tests/citation-word.test.js`
   - Archived `VALIDATION-40.1.0.md` as `VALIDATION-early-candidate.md`, removed obsolete probe scripts, and purged all historical `v40` references from maintenance and architecture documentation.
3. **Module Line Count & Architecture Compliance**:
   - Maintained all 27 source modules strictly under the `<= 360` lines limit, ensuring clean decoupling between citation data handling, tree icon/position patching, and window lifecycle.
